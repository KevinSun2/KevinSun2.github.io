# Website instructions

- Keep this a simple static website for GitHub Pages.
- Use plain HTML and CSS; add JavaScript only when a feature needs it.
- Keep explanations short and explain unfamiliar code in plain language.
- Keep the layout readable on both phones and computers.
- Use semantic HTML, visible keyboard focus, and accessible color contrast.
- Never put passwords, API keys, .env contents, or private personal information in files or commits.
- Use only personal information the owner has approved for this website.
- Check the changed files before each commit and commit each completed, verified change separately.
- Check links and the page layout after changes.
